# xiaozhangup-bot

自用机器人，目的是方便处理我的各种消息通知。

### 目前支持的功能
1. 根据所填写的关键词和群号自动抓取并总结通知内容，然后发送到 Todoist
2. Doist 任务命令（添加任务、列出板块、查看板块任务、删除任务）
3. 整理当日的天气和一些内容定时早报
4. `/ping` 回复 `pong`
5. 月度私信提醒（私聊引导设置、成功/失败群回执），见 [使用说明](doc/reminder/README.md)
6. 按会话模仿聊天风格（多组群聊/私聊配置、静默判断、延迟分条及新消息打断），见 [使用说明](doc/person/README.md)
7. 爱发电新成交订单群提醒（API 轮询、历史订单初始化、持久化去重），见 [使用说明](doc/afdian/README.md)
8. QQ MCP 服务（42 个工具、Streamable HTTP、资源订阅、消息与文件、群管理），见 [使用说明](doc/mcp/README.md)
9. `/x` Codex 群会话（引用回查、合并转发、图片、卡片、附件、语音转文字和视频抽帧），见 [使用说明](doc/codex/README.md)
